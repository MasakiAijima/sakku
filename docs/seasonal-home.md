# ホームの七十二候

ホームは `current.json` の承認済みリリースを表示する。現在の基本案は C/C′、配布版は c-v2。請求額の照合は利用者の指示で #19 の完了条件から除外した。

## 表示

- 保存済み700×700の72座標と見かけの大きさを使用する。進行、年、選択によって座標を変えない。
- 未到来は C′。到来済みは記録の有無にかかわらず C。
- 初回表示と年変更では、到来済みの候だけを古い順に成長させる。1候720ms、開始間隔45ms。成長が終わるとマスクを外し、完成画像を静止表示する。
- 同じ年で暦が進んだ場合は新たに到来した候だけを成長させる。選択変更では再生しない。
- 非表示中と Reduced Motion は到来済みを直ちに完成にする。復帰時に済んだ成長を繰り返さない。
- 現在候は進行数の隣に表示し、各画像の読み上げ名にも含める。画像は矢印、Enter、Spaceで選択でき、一覧でも同じ詳細を選べる。

暦は採用版の実際の日付とタイムゾーンで判定する。固定5日計算をしない。境界タイマー、focus、pageshow、visibilitychangeで再評価する。対応しない年は利用不可と表示し、近似しない。

## 実装の責務

`shared/seasonal-art.ts` は承認状態、SHA-256、72ID、パス、アンカー、画像境界を読み込み境界で検証する。`shared/seasonal-art-runtime.js` は描画、成長、選択を担当する。Reactは暦と画面の状態を渡し、公開オフライン画面も同じ描画コードを使用する。共有描画部品または採用暦を変更したときは、公開用の `seasonal-art-runtime.js` と `offline-calendar.json` も更新する。単体テストは両者の完全一致を確認する。起動時に生成AIを呼ばない。

画像が欠損した場合は利用可能な静止画像を残す。manifestが不正なら描画せず、利用不可を表示する。

## オフライン

ルートのService Workerは公開された季節素材と専用画面を保存する。オンラインでは通常のホームを返し、通信できない再読込では専用の季節画面を返す。認証済みホームのHTML、設定、記録、API応答を保存しない。初回の素材保存が完了するまでは、再起動後のオフライン表示は利用できない。

保存時はmanifestと216静止画像のSHA-256を確認し、すべて成功した候補だけを採用する。失敗時は以前のキャッシュを残す。オフライン画面にも年選択、候の詳細、同じ成長描画、日英切替を備える。現在季節年の範囲外では近似せず利用不可を表示し、対応年を明示選択できる。

## 検証

`node scripts/test-unit.mjs` で採用暦と画像manifestの正常・異常系を確認する。`node tests/seasonal-home-live.test.mjs` は実Chromeで0/12/42/72候、位置不変、選択、キーボード、日英、320〜1280px、文字200%、年境界、長期復帰、未対応年、成長の順序、生成API呼出しなし、完成後のSVG無更新を検証する。静止idleの確認は描画処理が落ち着くことの検証であり、実機フレームレート測定ではない。Playwrightの配置は `PLAYWRIGHT_MODULE` で指定できる。

`node tests/seasonal-home-offline.test.mjs` は通信断後のホーム再読込、全72候、実日付による年切替・境界・範囲外、日英、320px、個人データの非保存を確認する。

スクリーンショットは `output/seasonal-assets/home-review/`、CIでは `.test-artifacts/` に保存する。ローカルの型検査・ビルド・ブラウザー検証と、GitHubでのCI実行結果は区別する。

小画面の確認はMac上のChromeで画面幅を変更したもの。iOS/Androidの実機性能、実際のスクリーンリーダーでの操作、ホーム統合後の最終目視承認は未確認。これらを #16 の残条件として記録する。
