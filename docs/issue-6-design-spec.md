## 画面と操作

| 画面 | 操作 | 保存と戻る動作 |
|---|---|---|
| 記録 | 閲覧単位・期間を選択し、記録を開く | 詳細から戻っても選んだ期間を維持。ページの再読み込みをまたぐ保存は行わない |
| 01 | 日付・情景文を入力。補助入力を開閉。写真を追加・解除 | 補助欄を閉じても値を保持。画面間の移動は編集中データを保持 |
| 02 | 3候補から選択、同じ候補を再タップして訳と原文を切替、選んだ稿を編集 | 翻訳の切替は編集稿を上書きしない。他候補の選択はその候補へ切替 |
| 02 | 新しく詠む・推敲する | 成功時に新候補へ置換。失敗時は情景と選択稿を維持。実APIの品質評価は別途 |
| 02 | 情景を変更して戻る | 完成保存には候補の再選択を要求。編集稿の再確認と生成のやり直しを区別 |
| 01・02 | 下書きを保存 | サーバーへ明示保存。空の下書きや無効日付はAPIで拒否 |
| 03 | 完成記録、情景、任意の補助文・写真を見る | 編集は同じ記録の版を更新。競合はエラー表示 |
| 共有 | Haikuと日付の共有・コピー、カード書き出し | 情景文と気持ちは共有文に含めない。カードには添付写真を含める場合がある |
| 設定 | 名前、Haikuの流儀、表現、表示言語を保存 | 本人のアカウントに保存。過去の記録本文は変更しない |

編集中の別記録を開くときとログアウト時は既存の破棄確認を維持する。タブを閉じるときは `beforeunload` に依存する。端末やブラウザーを終了した場合の復元と自動保存は未実装であり、明示的な下書き保存が必要。
翻訳や生成の待機中の画面遷移、推敲欄の再描画後の保持は検証対象とする。

## 閲覧の期間契約

期間は `from` を含み、`to` を含まない日付範囲としてAPIに渡す。記録日は保存された `record_date` を使い、旅行や端末時刻の変更で再計算しない。

| 単位 | この版での操作 | 確定していない点 |
|---|---|---|
| すべて | 全期間の記録をページ取得 | 全件の固定スナップショットは保証しない |
| 日 | 日付を選択。その日の開始以上・翌日の開始未満 | 日付入力の初期値は既存どおり端末の今日。日記用時間帯はIssue #2 |
| 七十二候 | 利用者が開始日・終了日を指定して閲覧する試作 | 候名、候の対応、算出方法、地域、版。入力した期間を正式な候とは表示しない |
| 二十四節気 | 利用者が開始日・終了日を指定して閲覧する試作 | 節気名、各年の境界。等間隔や固定日では補わない |
| 一年 | 暦年の1月1日以上・翌年1月1日未満を閲覧する試作 | Sakkuの一年を暦年または立春始まりにするかはIssue #2 |

候・節気の期間は初期状態で未指定にする。正式な暦がない状態と、選択期間に記録がない状態を区別する。開始日以上・終了日未満の入力契約を画面に表示する。
不正日付・逆転・同じ開始終了・上限を超える翌日は取得前に拒否する。
期間を変えるとカーソルを破棄し、新しい範囲を最初から取得する。「続きを読み込む」は同じ範囲を送る。
読込失敗を空白期間として表示しない。未取得のページがある場合は、その状態を示し、読み込み済み記録だけで全期間の件数や空白を断定しない。

## ビジュアルと素材 v0.1

本番の基調は既存試作の生成り・緑を維持する。比較欄だけで寒い青と暖かい朱、目玉の有無を切り替える。比較の結果は記録本文・写真・日付に保存しない。
これはブラウザー内のCSS図形であり、生成画像の品質検証やdonchi作品の複製を行ったものではない。

| 用途 | この版 | 検証待ち |
|---|---|---|
| 写真 | 本人の記録に添えた実写真。個別記録と共有カードに表示 | 縦横比、被写体の切れ方、任意解除、実端末のアップロード |
| 日のモチーフ | CSSの丸と色面を比較する仮図形 | 一覧での識別性、小モチーフから記録を開く操作 |
| 記録の生成画像 | 未実装 | 写真との優先順位、生成条件、費用、失敗時表示、権利・品質確認 |
| 候・節気の表紙 | 未実装 | 小さな詩集としての構成、画像・文字の配置、暦の版との対応 |
| 季節配色 | 比較欄のみ。季節暦とは連動しない | 節気間の移り変わり、選択色のコントラスト、作家との共同制作 |

既存の画像・素材に版管理された原本はない。比較用素材の版はコードと本書のv0.1を組とする。
生成画像を採用する場合は素材ID、生成日時、ツール・モデル、プロンプト版、入力参照の権利、用途、採否理由を記録する。現在、生成画像のプロンプトや品質を確定したとは扱わない。

## デザイン値と適用

| 要素 | Webの既存値 | この版の位置づけ |
|---|---|---|
| 紙・文字・緑 | `#f5f3ed`、`#333c34`、`#435746` | 復元済み試作の基調。最終配色ではない |
| 補助文字 | `#5e675c` | 紙・パネル・淡い背景の上で4.5:1以上となるよう従来の色を調整 |
| 補助色・境界 | `#e5e8dc`、`#dcded3` | 背景と境界。境界色だけで状態を伝えない |
| 文字 | Arial、Hiragino、HaikuはGeorgia | 本文14px、Haiku23px、見出し30〜48pxを基準。拡大を許可 |
| 余白 | メイン横28px、小画面20px、カード間25px | 760px以下で1列。320pxでも操作を折り返す |
| 形 | 操作・記録カードの角丸3px、フィルター30px、モチーフは丸 | 見た目の役割を区別する |
| 操作 | 主要操作の最小領域44px、キーボードのfocus表示 | 小画面と文字拡大で確認する |
| 写真 | カードは `object-fit: cover`、個別画面は既存の写真枠 | 切り抜きは表示上のみ。写真原本や記録本文は変更しない |

比較欄の青は文字 `#24445c`・紙 `#f0f5f8`・色面 `#d6e7ef`・図形 `#96b7ca`、朱は文字 `#71382d`・紙 `#fff5ec`・色面 `#f0d2bf`・図形 `#c97258`。目は装飾として読み上げから除外し、各比較の名称で有無を伝える。これらはv0.1の試作値で、季節配色の採用値ではない。

Webの実際のスタイルは `app/globals.css`、共有値の予約は `shared/design-tokens.ts`。モバイルでは色・余白・形・用途を共有し、文字は端末の拡大設定、操作は44ptまたは48dpを下限として再検証する。React Nativeへの適用と実機検証は未実施。

## 判断履歴

| 日付 | 判断 | 状態と理由 |
|---|---|---|
| 2026-10-11 | 単位を直接選ぶ操作を実装 | 試作として採用。既存一覧へ追加でき、未確定の親子関係を断定しない |
| 2026-10-11 | 一年→節気→候→日の接近操作を延期 | 暦の親子関係と実機評価がないため。永久不採用ではない |
| 2026-10-11 | 候・節気は明示期間で検証 | 試作として採用。5日刻み・固定日から正式な季節を生成する案は不採用 |
| 2026-10-11 | 寒い青と朱、目玉あり・なしを比較欄に限定 | 検証待ちの候補を既存記録の見た目へ一括採用しない |
| 2026-10-11 | 編集稿と翻訳の表示切替を分離 | 同じ候補の再タップで編集内容が消える既存不具合を修正 |

Model the Domainの原則に従い、閲覧の単位と期間解決を1つのモデルにまとめる。Prove It Worksの原則に従い、実際の画面スクリプトをブラウザーで動かして確認し、実機評価と混同しない。
