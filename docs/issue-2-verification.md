| 項目 | 採用内容 |
| --- | --- |
| 地域・名称・読み | 日本の本朝七十二候。「こよみのページ」のCSV表記を保持 |
| 候入り日 | 太陽中心の視黄経5度刻みの通過を求めた出典CSVの日本時の日付 |
| 二十四節気 | 初候と対応。国立天文台の暦要項を照合基準とする |
| 日付境界 | Asia/Tokyoの午前0時。開始日を含み、次の開始日を含まない |

| 対応範囲 | 暦年・季節年とも2024〜2027。範囲外の記録を保持し、分類は利用不可 |
| 訂正 | 版付きJSONを保持。訂正版を追加し、過去の版を指定して再現する |

## 検証結果

Node.js 24で以下を実行し、すべて成功した。

```sh
node --test tests/calendar.test.mjs tests/archive.test.mjs
node scripts/calendar.mjs --check --require-year=2026
node output/issue-2/verify.mjs
```

- 既存テスト11件。二十四節気96件と収録済み国立天文台参照データの一致、重複・欠落・形式異常の拒否、再生成の一致、失敗時の現在版保持を含む。
- 2024年1月1日から2027年12月31日まで全1,461日が一意に候・節気・暦年へ分類された。
- 対応期間内の候入り日288件について、日本時間午前0時と直前1ミリ秒の切替を確認した。
- 4季節年の実立春境界、閏日、2026年1月1日の前年12月31日開始候、対応年外と版不一致の拒否を確認した。
- 端末時間帯をHonolulu・UTC・Tokyoに変更しても新規日付はJSTのままになることを既存テストで確認した。

全日検証スクリプトはローカルの `output/issue-2/verify.mjs` に保存した。今回の仕様確定では本番デプロイ・画面接続・DBの分類書き込みを行っていない。
