# モバイルトップ画面

2026-10-17に [Issue #6](https://github.com/MasakiAijima/sakku/issues/6) と [tldraw REVIEW](https://www.tldraw.com/f/7lB4rg6Mpd18ULTqJupJV) を基に実装した。

Orbit viewは承認済みの72候素材を拡大し、現在候のアンカーを初期位置の画面中央へ置く。背景だけを縦横にスクロールでき、候名・日付・ヘッダ・下部ボタンは固定する。「72候 · いまの候」と「期間」の補助ラベルは表示しない。円は画面外に見切れる。現在の節気、初候・次候・末候、候名、読み、期間を表示する。期間末日は採用暦の終了境界の前日とする。英語の月名と序数を使い、開始日と終了日を2行で表示する。

Haiku viewは現在の季節年の到来済み候を古い順に並べ、最新候を右側へ置く。同じ候に完成Haikuが複数あればアイコンを繰り返す。記録日とIDで古い順に並べる。完成Haikuがない候もアイコンを1つ表示し、＋と `tap to compose` を表示する。下書きと未到来の候は列に含めない。

Haiku本文にはプロフィール名だけを添える。日付は横スクロールの各アイコン下へ小さく表示し、最新候が未記載なら `today` とする。記録ありは記録日、過去の空候は候の開始日を使う。カードをタップすると原文、翻訳、情景と写真の順に切り替わる。アプリ言語と作句言語が一致する場合は翻訳をスキップする。現在の作句言語はEnglishである。

原文中の重要語を控えめな点線で示し、タップするとアプリ言語の解説を吹き出しで表示する。キーワード・ニュアンスの一覧説明は表示しない。表示中のカードだけ既存APIで解説と翻訳を取得し、原文・表示言語単位で再利用する。Orbitや非表示のカードでは取得しない。注釈の操作はカードを切り替えず、Escapeと外側のタップで閉じる。同じキーワードの複数箇所も別々に操作できる。写真は複数のサムネイルを表示し、タップで拡大ギャラリーへ進む。前後の画像・矢印キー・Escapeで操作できる。＋から既存の編集画面へ進む。現在候では今日のJST日付、過去の候では候の開始日を引き継ぐ。「作句しなおす」は対象の情景・Haiku・すべての画像を編集画面へ引き継ぐ。「書きかけを続ける」ボタンは表示しない。既存の一覧の作成導線は編集中の入力を維持する。書きかけがある状態で新規作成する場合は破棄の確認を表示する。

ヘッダの歯車は設定へ進む。画面下部の固定ボタンでOrbitとHaikuを切り替える。ボタンはアイコンのみとし、Haikuのアイコンは短・長・短の3本線で5-7-5を表す。読み上げ用の画面名は維持する。Haikuのアイコン下の候名と、ページ内の候名・期間は表示しない。Composeには工程の01/02/03、CAPTURE A MOMENT、導入の見出しと説明、日付の入力項目を表示しない。日付は内部に保持し、新規・過去候からの作成・再編集で元の規則どおり保存する。

起動時はOrbit、Haiku初回は現在候の最新Haikuを表示する。Haikuボタンの再タップで最新候へ戻る。アイコン列は横方向へスクロールでき、左右矢印とHome・Endでも選べる。従来の記録一覧と下書き一覧は設定の「すべての記録」から開く。

`app/seasonal-orbit.tsx` が暦とトップの切り替え、`app/haiku-view.tsx` が候ごとのHaiku取得・選択を持つ。編集・保存・設定は `public/screen.js` が持つ。React領域は既存のDOM翻訳処理から除外する。候の記録取得は季節年の期間で絞り、すべてのカーソルを取得してから空状態を判定する。取得失敗は再試行を表示する。保存成功でHaikuを再取得する。対応外の年の候は近似しない。

## 確認結果

Chromeで次を確認した。個人データ・実生成APIは使用せず、APIを固定応答に置き換えた。

- 現在候のアンカーと拡大したSVGの中心が一致する。
- 到来済み候だけが表示され、同じ候の2件のHaikuは2つのアイコンになる。
- 2ページ目のHaikuが表示され、未到来と下書きは除外される。
- 初回表示と再タップで最新候が選ばれ、該当アイコンまでスクロールする。
- 空状態から過去の候の日付を編集画面へ引き継ぐ。
- 下書き再開、破棄の取消・承認、生成候補の選択、保存後のアイコン追加が動作する。
- 設定との往復と英語への変更が動作する。
- 幅320・390・768・1280px、文字200%で横方向にはみ出さず、FABが下部切り替えの上に置かれる。
- 候入りの境界で現在候とHaiku列が進み、対応外の年では利用不可を表示する。
- 取得失敗を空状態と混同せず、再試行で復旧する。

再実行は `TEST_BASE_URL=http://127.0.0.1:5174 node tests/mobile-home-live.test.mjs`。Playwrightの配置は `PLAYWRIGHT_MODULE` で指定できる。既存の `seasonal-home-live.test.mjs` と `orbit-screen.test.mjs` からも同じ試験を実行する。画像は `output/mobile-home-review/` に保存する。
